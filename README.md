A deterministic Node-stdlib-only program that draws one 1024x1024 PNG newspaper
front page summing up the world news of Sunday 22 November 2026: a magnitude 6.7
earthquake in Peru's Andes, UN talks on lethal autonomous weapons falling short,
the Tasis Alliance seizing Bau in Sudan's Blue Nile, Hong Kong's Election
Committee vote, Trump on a lasting Iran deal, toxic liquor deaths in Manipur,
and the EU's proposed 3% levy on big tech.

Run it with:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

It writes `out/entry.png` (under 1 MiB). Run twice and the bytes are identical.
